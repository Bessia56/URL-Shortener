# URL Shortener API

REST API для создания и управления короткими ссылками.

## Установка

### Клонирование репозитория

```bash
git clone https://github.com/Bessia56/URL-Shortener
cd url-shortener
npm install
```
## Настройка

Скопируйте файл `.env.example` в `.env` в корне проекта и укажите параметры:

```env
PORT=3001
BASE_URL=http://localhost:3001
DATABASE_FILENAME=database.sqlite
```
Выполните команду в терминале из корневой папки проекта:
```
cp .env.example .env
```
### Запуск

```bash
npm start
```

## API

### Проверка доступности API

Проверяет, отвечает ли API.

#### Запрос

- **Метод:** `GET`
- **Путь:** `/health`
- **Тело запроса:** отсутствует

Пример:

```bash
curl http://localhost:3001/api/v1/links/health
```

#### Успешный ответ

Код: `200 OK`

```json
{
  "status": "OK"
}
```

### Создание короткой ссылки

Создаёт короткую ссылку для исходного URL.

#### Запрос

- **Метод:** `POST`
- **Путь:** `/api/v1/links/`
- **Тело запроса (JSON):**

```json
{
  "url": "https://example.com/article",
  "customCode": "my-article",
  "expiresAt": "2099-12-31T23:59:59.000Z"
}
```

#### Допустимые значения

| Поле | Тип | Обязательное | Значения |
|---|---|---|---|
| `url` | string | Да | Исходный URL|
| `customCode` | string | Нет | Латинские буквы, цифры, `_` и `-`; максимум 50 символов |
| `expiresAt` | string / дата | Нет | Дата в будущем |

Поля customCode и expiresAt необязательны. Если `customCode` не передан, код генерируется автоматически. По умолчанию он состоит из 5 символов: латинских букв в верхнем и нижнем регистре и цифр. Если expiresAt отсутствует, ссылка не истекает.


#### Пример запроса

```bash
curl -X POST http://localhost:3001/api/v1/links/ \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com"}'
```

#### Успешный ответ

Код: `201 Created`.

```json
{
  "data": {
    "id": "c8b3a0d2-4f4c-4e4c-8a9a-2a3b4c5d6e7f",
    "url": "https://example.com/articles/nodejs",
    "shortCode": "nodejs-guide",
    "shortUrl": "http://localhost:3001/nodejs-guide",
    "createdAt": "2026-10-20T08:00:00.000Z",
    "expiresAt": "2026-11-01T00:00:00.000Z",
    "clickCount": 0,
    "lastClickedAt": null
  }
}
```


#### Возможные ошибки

| Код | Описание |
|---|---|
| `400` | Переданы некорректные данные |
| `409` | Пользовательский короткий код уже занят |

### Получение списка ссылок

Возвращает список ссылок с пагинацией и сортировкой.

#### Запрос

- **Метод:** `GET`
- **Путь:** `/api/v1/links/`
- **Тело запроса:** отсутствует
- **Query-параметры:** необязательные

Пример:

```bash
curl "http://localhost:3001/api/v1/links/?limit=10&offset=0&sort=clickCount&order=desc"
```

#### Допустимые значения

| Поле | Тип | Обязательное | Значения |
|---|---|---|---|
| `limit` | integer | Нет |Количество записей на странице. По умолчанию `20`, минимум `1`, максимум `100`. |
| `offset` | integer | Нет | Количество записей, которые нужно пропустить. По умолчанию `0`.|
| `sort` | string | Нет | `createdAt` или `clickCount`; по умолчанию `createdAt` |
| `order` | string | Нет | Направление сортировки: `asc` или `desc`; по умолчанию `desc`.|

#### Успешный ответ

Код: `200 OK`.

```json
{
  "data": [
    {
      "id": "c8b3a0d2-4f4c-4e4c-8a9a-2a3b4c5d6e7f",
      "url": "https://example.com",
      "shortCode": "Ab3xYz9",
      "shortUrl": "http://localhost:3001/Ab3xYz9",
      "createdAt": "2026-10-20T08:00:00.000Z",
      "expiresAt": null,
      "clickCount": 3,
      "lastClickedAt": "2026-10-20T09:00:00.000Z"
    }
  ],
  "pagination": {
    "limit": 10,
    "offset": 0,
    "total": 1
  }
}
```

#### Возможные ошибки

| Код | Описание |
|---|---|
| `400` | Переданы некорректные query-параметры |

### Обновление короткой ссылки

Изменяет пользовательский короткий код и/или срок действия ссылки.

#### Запрос

- **Метод:** `PATCH`
- **Путь:** `/api/v1/links/:id`
- **Тело запроса (JSON):** передайте одно или оба поддерживаемых поля

Пример изменения короткого кода:

```json
{
  "customCode": "new-code"
}
```

Пример изменения срока действия:

```json
{
  "expiresAt": "2099-12-31T23:59:59.000Z"
}
```

Чтобы убрать срок действия, передайте `null`:

```json
{
  "expiresAt": null
}
```

Пример запроса:

```bash
curl -X PATCH http://localhost:3001/api/v1/links/REPLACE_WITH_LINK_ID \
  -H "Content-Type: application/json" \
  -d '{"customCode":"new-code"}'
```

#### Допустимые значения

| Поле | Тип | Обязательное | Значения |
|---|---|---|---|
| `id` | UUID | Да | ID ссылки, передаётся в URL |
| `customCode` | string | Нет | Латинские буквы, цифры, `_` и `-`; максимум 50 символов |
| `expiresAt` | string / дата / `null` | Нет | Дата в будущем либо `null`, чтобы убрать срок действия |

Необходимо передать хотя бы одно из полей `customCode` или `expiresAt`.

#### Успешный ответ

Код: `200 OK` — возвращает обновлённый объект ссылки
```json
{
	"data": {
		"id": "5e1469b7-23a1-4a41-bc9a-e2d4c80fe76e",
		"url": "https://docs.google.com/document/d/11582Cj",
		"shortCode": "love",
		"shortUrl": "http://localhost:3001/love",
		"createdAt": "2026-10-28T05:46:29.398Z",
		"expiresAt": null,
		"clickCount": 0,
		"lastClickedAt": null
	}
}
```

#### Возможные ошибки

| Код | Описание |
|---|---|
| `400` | Некорректные данные или не переданы поля для изменения |
| `404` | Ссылка с указанным ID не найдена |
| `409` | Указанный короткий код уже используется |

### Переход по короткой ссылке

Перенаправляет пользователя на исходный URL по короткому коду. При успешном переходе обновляет статистику ссылки.

#### Запрос

- **Метод:** `GET`
- **Путь:** `/:code`
- **Тело запроса:** отсутствует

Пример:

```bash
curl -i http://localhost:3001/REPLACE_WITH_SHORT_CODE
```

Вместо `REPLACE_WITH_SHORT_CODE` укажите короткий код ссылки.

#### Допустимые значения

| Поле | Тип | Обязательное | Значения |
|---|---|---|---|
| `code` | string | Да | Короткий код существующей ссылки, передаётся в URL |

#### Успешный ответ

При успешном переходе сервер возвращает 302 Found и передаёт исходный URL в заголовке Location. Одновременно обновляются счётчик переходов и время последнего перехода.
#### Возможные ошибки

| Код | Описание |
|---|---|
| `404` | Короткая ссылка не найдена |
| `410` | Срок действия ссылки истёк |
